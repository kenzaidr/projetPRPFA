frontend/

    │   └── App.css             → App styles
    │
    ├── 📁 pages/               ⭐ MAIN PAGES
    │   └── HomePage.tsx         → Landing page (converted from HTML)
    │
    ├── 📁 components/          (Reusable UI components)
    │   └── driver/

    ├── 📁 features/            (Feature modules - future development)
    │   ├── admin/admin.jsx
    │   ├── auth/auth.jsx

    │   ├── notification/notification.jsx

    ├── 📁 assets/              ⭐ STATIC ASSETS

    │
    ├── 📁 shared/              (Shared code)
    │   ├── components/
    │   ├── hooks/
    │   └── lib/
    │
    ├── 📁 types/               (TypeScript types)
    │
    ├── 📁 i18n/                (Internationalization)
    │   └── locales/

    └── 📁 main/                ⚠️ OLD FILES (can be deleted)

🎯 KEY FILES TO KNOW:

1. HomePage.tsx          → Main landing page component
2. translations.ts       → Language switching system
3. styles.css            → Custom animations & RTL support
4. App.tsx               → App entry component
